    nist-nvd

    NIST National Vulnerability Database (NVD) LinkML Schema. Captures enriched vulnerability records, CVSS metric views, CPE applicability statements, weakness attributions, reference resource tags, KEV indicator details, and NVD lifecycle status transitions.

    URI: https://w3id.org/lmodel/nist-nvd

    Name: nist-nvd

    Class Description
    Configuration Logical grouping of CPE match expressions
    CPEConfiguration Logical grouping of CPE match criteria for affected software
    CPEMatch Leaf-level CPE match criterion and optional version bounds
    CVSSMetric Individual CVSS vector and score attribution
    CVSSScoreNote Additional explanatory note for CVSS display conditions
    Impact Assessment of the vulnerability's impact and severity
    KnownExploitedVulnerability CISA KEV information rendered on the NVD detail page
    MetricSet Container for all metric views across CVSS versions
    Product Software or hardware entity affected by the vulnerability
    Reference External reference such as an advisory or article

    Weakness Weakness classification from CWE or a similar taxonomy
