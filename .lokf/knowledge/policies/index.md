# Policies

* [Security policy](security-policy.md) - `SECURITY.md`: report by GitHub's private vulnerability reporting, only the latest release gets fixes, what each workflow may do, what the watch and the feed fetch read, and what is not covered, such as NVD's data and a flaw in a product NVD lists.
* [AI covenant](ai-covenant.md) - The rules for AI-assisted work here: a person owns every contribution, an element says what NVD says, a mapping is read at its source and never guessed, descriptions are one's own words, and the scheduled librarian's changes need a person's review.
* [License and attribution](license-and-attribution.md) - The code is under Apache-2.0 and the bundle under CC BY 4.0. NOTICE carries NVD's notice that it does not endorse or certify this product, NIST's statement on its works, FIRST's position on the CVSS schemas, and why the SSVC file's descriptions are not copied.
