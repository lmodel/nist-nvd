# National Vulnerability Database (NVD)

The National Vulnerability Database (NVD) republishes each CVE record with its own analysis: a status, scores, weaknesses and the product configurations that have the vulnerability. Its API has four responses, and each has a JSON schema that the National Institute of Standards and Technology (NIST) publishes.[^about.md]
